## Analisador Léxico 

Este projeto tem como objetivo **simular o funcionamento de um analisador léxico**, utilizando o conceito de **Autômato Finito Determinístico (AFD)**.  
Foi desenvolvido em **JavaScript**, com uma interface interativa em **HTML** e **CSS**, permitindo ao usuário **adicionar**, **remover** e **verificar palavras** em um dicionário dinâmico.



## O que o sistema faz

O sistema representa visualmente um **autômato** que reconhece palavras adicionadas ao dicionário.  
Cada palavra é convertida em **estados e transições**, formando uma estrutura lógica que simula como um **analisador léxico** identifica tokens válidos.

Com ele, é possível:
- Adicionar palavras formadas apenas por letras minúsculas (`a-z`);
- Remover palavras do dicionário;
- Visualizar a **tabela de transições** gerada automaticamente;
- Simular o **reconhecimento de palavras**, mostrando passo a passo as transições do autômato;

## Conceitos Envolvidos

- **Autômato Finito Determinístico (AFD)**  
  Representa graficamente o reconhecimento de cadeias (palavras) a partir de um alfabeto.  

- **Análise Léxica**  
  Primeira etapa da compilação, responsável por identificar padrões (tokens) em um texto.  

- **Transições e Estados**  
  Cada letra de uma palavra gera uma transição para um novo estado. O último estado indica aceitação (palavra reconhecida).
  

##  Tecnologias Utilizadas

- **JavaScript** – lógica do autômato e manipulação do DOM  
- **HTML5** – estrutura da interface  
- **CSS3** – estilização e efeitos visuais
